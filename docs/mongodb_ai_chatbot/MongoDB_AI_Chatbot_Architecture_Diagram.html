When to Use Each Approach
① Text-to-MQL
  • 🔵 Structured collections (orders, users)
  • 🔵 Filter by field value or date range
  • 🔵 Aggregations, counts, averages
  • 🔵 Joining collections ($lookup)
  • 🔵 Real-time analytics / dashboards
  • 🔵 Top-N ranking queries
② RAG + Vector Search
  • 🟣 Unstructured text (articles, notes)
  • 🟣 Semantic similarity ("find like X")
  • 🟣 Q&A over document collections
  • 🟣 Knowledge base chat
  • 🟣 Product description matching
  • 🟣 Support ticket analysis
③ Atlas Full-Text Search
  • 🟡 Keyword / phrase search
  • 🟡 Fuzzy / typo-tolerant matching
  • 🟡 Autocomplete / search-as-you-type
  • 🟡 Name / tag / label lookups
  • 🟡 Wildcard text search
  • 🟡 Highlighted search results

All three approaches are registered as separate LangGraph tools — the LLM autonomously routes each question to the correct tool at runtime.
Security: use a read-only MongoDB user · validate generated MQL before execution · block $where / $function operators
